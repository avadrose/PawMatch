# PawMatch

PawMatch is a dog adoption and social networking platform built with Python, Flask, PostgreSQL, SQLAlchemy, and JavaScript.

The application will allow users to browse adoptable dogs, create profiles for their own dogs, save favorites, submit adoption inquiries, arrange playdates, send messages, and interact with other dog owners.

## API

PawMatch will use a custom REST API built with Flask.

The PawMatch API will manage:

- Users
- Dog profiles
- Shelters and rescues
- Favorites
- Adoption requests
- Playdate requests
- Messages
- Reviews

Dummy data will be used during development and user-generated data will populate the application as users interact with PawMatch.

PawMatch may also use the Petfinder API as a supplemental source for adoptable dog listings.
