# PawMatch

PawMatch is a dog adoption and social networking platform built with Python, Flask, and PostgreSQL.

## API

PawMatch will use a custom REST API built with Flask to manage users, dog profiles, favorites, adoption requests, playdate requests, messages, and reviews.

A supplemental external API may also be used for adoptable dog information:

Petfinder API:
https://www.petfinder.com/developers/
